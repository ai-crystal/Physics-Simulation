# 前言

物理模拟的性能问题，很少是"算法不够聪明"，更多是"内存没喂饱"。

一个 SPH 求解器，数学上每个粒子要和邻居算几十次，真正的瓶颈却常常是从显存里把邻居的位置读进来的那几次访存。一个多重网格，收敛率很好，可在 GPU 上如果每一层都启动一次核函数，启动开销会把收益吃掉。这本册子讲的就是这些不太出现在论文里、却决定程序能不能跑起来的事。

内容按"硬件—数据—算法—系统"四层组织。先讲并行从哪来、为什么物理大多是带宽受限；再讲数据布局与 GPU 模型；然后是稀疏网格、线性求解、粒子邻域、图着色这些具体算法；最后是耦合、确定性、集群与性能分析。

书里不给"某引擎快多少倍"的数字。硬件、场景、精度一变，这些数字就没有意义。能给的是判断方法：先测什么、看哪个计数器、按什么顺序优化。

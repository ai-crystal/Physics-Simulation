# 前言

这本书讲的是屏幕上的世界是怎么动起来的。

游戏里一面旗帜被风吹起，电影里一堵墙被撞碎，手机上一杯水被晃出波纹，这些画面背后是同一类工作：把连续的物理定律切成计算机能处理的有限块，在每一帧里算一遍，再让它看起来像真的。这件事有个朴素的名字，叫物理模拟。

它难，但不是因为数学有多深。真正难的是取舍。真实世界的自由度是无限的，计算机只能算有限个；物理定律是连续的，计算机只能一步一步走；一帧只有十六毫秒，解一个方程的时间不能超过它。于是每一个能跑起来的模拟器，都是在一堆互相冲突的要求之间找到的一个平衡点。刚体要稳，布料要软，流体要活，颗粒要真，而它们常常不能同时满足。

这套书想做的事，是把这些取舍讲清楚。第一册是入门，尽量铺开：从伽利略的斜面讲到今天的可微求解器，从台球碰撞讲到雪崩与爆炸，把整个领域的版图先画出来。它不追求公式的完整，也不要求读者有图形学背景，读完应该能知道每一类现象大致归哪一类方法管，遇到一个新问题该往哪个方向找答案。

后面的册子按专题展开。数学基础单独成册，因为模拟里的数学和工科课本里的并不完全一样，它更关心离散之后的矩阵长什么样、条件数有多大、能量会不会发散。刚体与碰撞、柔体布料与断裂、流体与烟火、颗粒与物质点法，各自成册，讲到自己那一块的主流方法和工程细节。最后两册讲实现与前沿：一册讲 GPU 与大规模并行，一册讲可微物理和神经模拟。

各册之间共享一套术语，但不互相引用。你可以从任何一本开始，遇到不熟悉的记号再回头查。

书里的插图都是程序画出来的，代码随书提供，改参数就能重画。涉及性能对比的图只使用有出处的数据，没有可靠来源的地方宁可不画。公式用 KaTeX 排版，网页和 PDF 里都可以复制。

物理模拟是一个需要动手的领域。读懂一篇论文和写出一个不炸的求解器，中间隔着很多次失败。如果这本书能让你在失败的时候知道该怀疑哪一处，它的目的就达到了。

# 术语中英对照

| 中文 | 英文 | 一句话说明 |
|---|---|---|
| 刚体 | rigid body | 形状与质量分布不随运动改变的物体 |
| 柔体 | deformable body | 受力后形状会改变的连续介质 |
| 约束 | constraint | 对状态施加的等式或不等式条件 |
| 时间步进 | time stepping | 把连续时间的演化切成离散帧 |
| 隐式积分 | implicit integration | 用下一时刻的力反解下一时刻的状态 |
| 物质点法 | material point method | 粒子携带物质、网格负责求解的混合方法 |
